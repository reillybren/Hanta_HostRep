# Hanta_HostRep
Repository for the code and data associated with an analysis of host repertoire evolution of orthohantaviruses conducted with RevBayes.

The files are split into six folders for the six different model/data combinations used.
-
-MEO= Murid and Eulipotyphlan associated orthohantaviruses

-NSO= Neotomine and Sigmodontine associated orthohantaviruses

-2= 2 state model, only host/nonhost, 0/2

-3= 3 state mode, nonhost, secondary host, primary host 0/1/2

-clado= host cladogenic distances

-tc= time calibrated host distances

The .nex files contain the state coding for host repertoire model.

Scripts
-
The .Rev files are the rev script for each model
